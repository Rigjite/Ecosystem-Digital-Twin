# Цифровой двойник экосистемы — навык для ИИ-агентов

[English](README.md) | Русский

Навык (Agent Skill) для проектирования и ведения **цифровых двойников
экосистем**: прудов и озёр, участков рек, сельскохозяйственных земель,
воздушных бассейнов и территорий охраны флоры и фауны.

Двойник, построенный по этому навыку, — живая модель реального места,
связанная с доказательствами. Она отражает текущее состояние системы,
заранее предупреждает об ухудшении и проверяет вмешательства в модели —
до того, как кто-либо затронет реальную систему. Два назначения, в этом
порядке: **консалтинговый продукт** для заказчика (хозяйство,
управляющий водоёмом, природоохранный проект, муниципалитет) и
**исследовательский инструмент** для собственной научной работы
оператора.

Текущая версия: **2.0** (2026-10-21). Лицензия: CC BY 4.0.
Основной текст навыка и все справочники — на английском языке (файл
`SKILL.md` и папка `references/`); эта страница — русское описание
пакета.

## Что охватывает навык

- **Полный цикл построения (фазы 0–6):** паспорт объекта и постановка
  решения → инвентаризация данных с приоритетом открытых источников →
  модель состояния → калибровка и проверка → мониторинг и постоянная
  верификация → сценарии улучшения → итоговый пакет с провенансом
  (манифест RO-Crate).
- **Многоуровневый каталог индикаторов** (около 200 индикаторов, 19
  разделов): климатические драйверы, качество воздуха и выпадения,
  полный гидрометрический блок, гидрохимия и формы биогенов, эвтрофикация,
  загрязнители, донные отложения, грунтовые воды, почвы и земли,
  ландшафт, флора, микроводоросли и фитопланктон, санитарная и
  технологическая микробиология, беспозвоночные, рыбы и дикая фауна,
  функции экосистемы; у каждого индикатора — уровень (базовый /
  условный / исследовательский) и именованный источник порога.
- **Слой доказательств:** научная литература с маршрутизацией по
  платформам PubMed / PMC, Europe PMC, OpenAlex, Crossref (и
  региональным источникам) и строгой дисциплиной: сначала стандарты и
  руководства, реферат отбирает — полный текст решает, переносимость
  проверяется.
- **Аналитика и предвосхищение:** спасение исторических данных с
  реестром смещений и разрывов, анализ закономерностей, каталог
  событий, аудит предсказуемости, проверка прогнозов по событиям,
  реестр рисков и заранее согласованные планы превентивных действий
  «триггер — действие — реакция».
- **Неопределённость и доказательство эффекта:** вычисляемые бюджеты
  неопределённости, глобальный анализ чувствительности, планирование
  измерений по ценности информации, журнал прогнозов с предварительной
  регистрацией и контрфактический двойник «без вмешательства», который
  работает параллельно после внедрения меры, — улучшение измеряется, а
  не декларируется.
- **Управляемая мультиагентная работа:** три уровня оркестрации,
  специалисты с различными экспертными персонами, письменные контракты
  задач и независимая «красная команда» на воротах проектирования,
  калибровки и сдачи.

## Несгибаемые правила

- Никаких выдуманных данных — каждое значение прослеживается к
  источнику с датой, методом и разрешением; отсутствие значения —
  названный пробел.
- Некалиброванная сборка не сдаётся как двойник — она письменно
  помечается прототипом.
- Точные координаты чувствительных видов не публикуются никогда
  (обобщение по практике GBIF для чувствительных данных).
- Природоподобные решения (nature-based solutions) оцениваются раньше
  инженерных в каждом сценарном раунде; бремя обоснования лежит на
  инженерном варианте.

## Установка

Папка навыка должна называться `ecosystem-digital-twin` — как поле `name`
в `SKILL.md`, независимо от имени репозитория.

- **Claude Code:** `git clone https://github.com/Rigjite/Ecosystem-Digital-Twin ~/.claude/skills/ecosystem-digital-twin`
- **Приложение Claude (claude.ai, компьютер, телефон):** упакуйте папку в
  zip так, чтобы `ecosystem-digital-twin/SKILL.md` лежал в корне архива, и
  загрузите его как собственный навык в настройках навыков приложения.
- **Другие клиенты Agent Skills:** скопируйте папку в их каталог навыков.

Проверка установки из папки навыка: `python3 tests/check_package.py --strict`.

## Быстрый старт

1. Прочитайте `references/quick-start.md` — путь из десяти шагов на
   одной странице для первой или малой сборки.
2. Заполняйте по ходу пять бланков из `assets/templates.md`: паспорт
   объекта, реестр рисков, план «триггер — действие — реакция», карточка
   варианта, запись журнала прогнозов.
3. Держите рядом `examples/lake-example.md` — одно маленькое озеро,
   проведённое через все бланки от начала до конца.

## Структура пакета

| Путь | Содержание |
|---|---|
| `SKILL.md` | Сам навык: правила, фазы, модули по типам объектов, ворота качества |
| `references/indicators.md` | Многоуровневый каталог индикаторов и источники порогов |
| `references/data-sources.md` | Открытые источники данных и стандарты интероперабельности (SensorThings, WaterML 2.0, Darwin Core, EML, STAC, CF) |
| `references/evidence-sources.md` | Маршрутизация литературных платформ, протокол запросов, иерархия доказательств |
| `references/analytics-forecasting.md` | Спасение истории, закономерности, каталог событий, прогнозирование, реестр рисков, превентивные планы |
| `references/uncertainty-decision.md` | Количественная неопределённость, ценность информации, журнал прогнозов, контрфактический двойник |
| `references/orchestration.md` | Уровни мультиагентной работы, контракты ролей, независимость, ворота красной команды |
| `references/scenarios.md` | Библиотека сценариев улучшения |
| `references/world-practice.md` | Обзор мировой практики, на которой построен дизайн (Destination Earth, BioDT, Цифровой двойник океана ЕС, Delft-FEWS, фермерские двойники Вагенингена) |
| `references/quick-start.md` | Путь исполнения на одной странице и карта файлов |
| `assets/templates.md` | Пять заполняемых бланков |
| `examples/lake-example.md` | Разобранная миниатюрная сборка (все значения учебные) |
| `scripts/qc_series.py` | Контроль качества рядов: диапазон, скорость изменения, «залипание» датчика, дубли, пропуски, сверка с соседней станцией, точка разрыва; только флаги |
| `scripts/trend_test.py` | Манн–Кендалл и наклон Сена по сегментам между зарегистрированными разрывами; сезонный тест Кендалла; учёт автокорреляции |
| `scripts/skill_scores.py` | Калибровка и проверка: заранее объявленная отложенная выборка, наивные эталоны, NSE/KGE/RMSE, POD/FAR/CSI, Брайер с таблицей надёжности |
| `scripts/uncertainty_budget.py` | Бюджет неопределённости по источникам из ансамблевых прогонов; интервал только из совместного ансамбля |
| `scripts/alert_bands.py` | Жёлтая и красная зоны тревоги с названным источником порога и окном устойчивого превышения |
| `scripts/registry.py` | Журнал прогнозов только на дозапись, с хеш-цепочкой; оценка прогнозов строго в зарегистрированном виде |
| `scripts/generalize_coords.py` | Огрубление координат чувствительных видов (категории GBIF, минимум 0,1°) с проверкой перед передачей |
| `scripts/build_manifest.py` | Пакет провенанса RO-Crate 1.1; проверка, что каждое ключевое число прослежено и процитировано |
| `scripts/evidence_search.py` | Поиск литературы по PubMed, Europe PMC, OpenAlex, Crossref; нормализованный JSON на выходе |
| `tests/test_scripts.py`, `tests/check_package.py` | Юнит-тесты скриптов и проверка пакета (`python3 -m unittest discover -s tests`) |
| `tests/TESTS.md` | Поведенческие и автоматические тесты (T1–T27) с таблицей прослеживаемости и журналом прогонов |
| `CHANGELOG.md` | История версий |

## Разработка и оценка

Навык развивался итеративно: каждый слой возможностей добавлялся против
режимов отказа предыдущей версии, а пакет проходил повторные раунды
оценки (журнал прогонов с оценками, найденными и исправленными
дефектами — в `tests/TESTS.md`). С версии 2.0 правила, которые можно
вычислить, обеспечиваются скриптами с юнит-тестами; поведенческие тесты
исполняются на живых проектах, и в журнале честно указано, какие ещё
ожидают первого живого применения.
